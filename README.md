# Firefly meadow

A cozy look for the Claude desktop and mobile apps: fireflies drifting over a
dusky meadow under a low moon, with the app's colours tinted plum and firefly
gold to match. The meadow starts with six fireflies; more gather as the
session's context window fills, up to sixty when it is full. The scene stays
dark in both light and dark mode. The terminal and editors draw no backdrop.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install firefly-meadow --marketplace oswahmahmood/firefly-meadow
```

Answer `y` to add the marketplace, then press Enter for the user scope.

From a shell:

```
claude plugin install firefly-meadow --marketplace oswahmahmood/firefly-meadow
```

In the desktop app, where `/plugin` does not run: click + next to the prompt
box, then Plugins, Add marketplace with `oswahmahmood/firefly-meadow`, then Add plugin.

The meadow draws in the desktop and mobile apps for sessions that run on your
own computer. The terminal and editors draw no backdrop.
